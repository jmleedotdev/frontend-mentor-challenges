# Frontend Mentor Challenges

Independent frontend challenges presented in a shared gallery.

## Language

### Password generator

**Character category**: A group of characters eligible for a generated password: uppercase letters, lowercase letters, numbers, or symbols. Every selected category must be represented in the generated password.
_Avoid_: Character type

**Generated password**: The password produced by the most recent successful generation. Changing settings does not change this password.
_Avoid_: Preview password

**Password strength**: An estimate of the generated password's resistance to guessing, expressed as Too Weak, Weak, Medium, or Strong. It describes the generated password, not unused settings, and is not a security guarantee.
_Avoid_: Password validity
