# Frontend Mentor Challenges

Independent frontend challenges presented in a shared gallery.

## Language

### Frontend quiz

**Start menu**: The screen that welcomes the learner and presents the available quiz subjects before a quiz begins.

**Subject**: A frontend knowledge area covered by a quiz: HTML, CSS, JavaScript, or Accessibility.

**Attempt**: One complete run through the questions for a selected subject, ending in a score.
_Avoid_: Round

**Selected answer**: The learner’s current choice for a question before submission. It can still be changed and has not been evaluated.

**Submitted answer**: The learner’s confirmed choice for a question. It is final for that question and has been evaluated against the correct answer.

**Results view**: The screen shown after the learner completes a quiz, summarizing the subject and final score.

**Score**: The number of correctly submitted answers out of the total questions in a completed quiz.

### Password generator

**Character category**: A group of characters eligible for a generated password: uppercase letters, lowercase letters, numbers, or symbols. Every selected category must be represented in the generated password.
_Avoid_: Character type

**Generated password**: The password produced by the most recent successful generation. Changing settings does not change this password.
_Avoid_: Preview password

**Password strength**: An estimate of the generated password's resistance to guessing, expressed as Too Weak, Weak, Medium, or Strong. It describes the generated password, not unused settings, and is not a security guarantee.
_Avoid_: Password validity
